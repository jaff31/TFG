# 📚 Aplicación Web para Gestión del Progreso de Alumnos

Esta aplicación web permite al profesorado gestionar el seguimiento académico del alumnado de forma organizada y eficiente. Incluye funcionalidades para registrar tareas, visualizar el rendimiento individual de cada estudiante y generar informes personalizados.

## 🧩 Características principales

- Registro de alumnos y tareas.
- Visualización del progreso académico.
- Generación de informes detallados.
- Acceso diferenciado por roles (profesorado / administración).

## 🏗️ Arquitectura

La aplicación sigue una arquitectura **cliente-servidor**:

- **Frontend**: HTML, CSS, JavaScript, PHP.
- **Backend**: API REST desarrollada en Spring Boot (Java).
- **Base de datos**: MySQL (relacional).


## 🛠️ Tecnologías utilizadas

- HTML5 / CSS3
- JavaScript
- PHP
- Java + Spring Boot
- MySQL
- Git + GitHub
